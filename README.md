# Анатомия — учебная платформа (публичная сборка)
Статический интерфейс для чтения русско-латинских учебных конспектов и работы с 3D-атласом. Демо, неофициальный проект, не является ресурсом МГУ.
Исходные файлы приложения и приватные данные отсутствуют в этом репозитории. Приведены только опубликованные фронтенд-файлы и учебные модели с атрибуцией.
Используются объекты BodyParts3D (см. LICENSE/metadata в models). Точность каждой анатомической структуры требует проверки, не использовать для медицинских решений.
